# Earnings Calendar & Dossier Linker

## Overview
Connects qualitative fundamental balance sheet data with quantitative 5-minute candlestick price action by embedding the local report file path directly into the Excel rows.

## Operational Logic
1. When a stock reports quarterly earnings, obtain the local file path generated by `financial_filings_harvester.py`.
2. Extract summary metrics: Revenue YoY growth %, Net Margin %, Free Cash Flow.
3. Record the local dossier path in the `Financial_Report_Path` column of `market_chronos_master_5m.xlsx`.
4. Enables F.R.I.D.A.Y. to retroactively evaluate fundamental health alongside technical chart setups during 1-month and 6-month retrospective reviews.
